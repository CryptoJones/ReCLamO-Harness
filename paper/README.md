# Paper: Recursive Language Models on Local Hardware (DRAFT)

**Status: DRAFT. Results pending. Not for citation or submission.**

A replication-and-measurement study of Recursive Language Models
([arXiv 2512.24601](https://arxiv.org/abs/2512.24601)) with a locally served model, built
on this repository's harness and its independent evaluation set. Author: Aaron Kingsley
Clark (Applied Artificial Intelligence, Eastern University). Tracked in
[#66](https://github.com/CryptoJones/ReCLamO-Harness/issues/66).

## What is final and what is not

- **Written:** introduction, related work, the harness (method), the evaluation set and
  its audits, the evaluation design and the draft hypotheses, threats to validity,
  future work, and the AI-assistance disclosure.
- **Preliminary, labelled as such:** the pilot (seeds 2-3, n=16 per cell) and the
  measurement lessons it taught. The draft draws no conclusion from it.
- **Pending:** every main-study number. In the PDF these show as orange `[PENDING: ...]`
  boxes; open questions show as red `[TODO: ...]`.

## Files

| Path | Contents |

## Regenerating the tables

The run files live under `runs/exp-v02/` in a working checkout (not in git). Standard
library Python only.

```sh
# Pilot: seeds 2-3, re-graded with the round-3.1 scorers (runs/exp-v02/rescored/)
python3 paper/analysis/make_tables.py --runs runs/exp-v02

# Optional pilot side runs (8B planner, Laguna, Llama 3.3 70B), from their archive
python3 paper/analysis/make_tables.py --runs runs/exp-v02 --side /path/to/paper-src

# Main study, once the grid is complete: writes tables/main_*.tex, which main.tex
# picks up automatically in place of the PENDING boxes
python3 paper/analysis/make_tables.py --runs runs/exp-v02 --stage main --seeds 2-9
```

Statistics: Wilson 95% intervals for exact-match rates, bootstrap 95% intervals for mean
scores and paired differences (10,000 resamples, fixed seed), and McNemar's exact test
for paired exact-match comparisons.
